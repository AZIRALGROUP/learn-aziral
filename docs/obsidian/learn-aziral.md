# learn-aziral

**LMS-поддомен `learn.aziral.com`** — платформа курсов и тестов, работающая как отдельный
SPA-фронтенд поверх общего бэкенда `aziral.com`.

> [!info] Суть в одном абзаце
> Это **чисто клиентское приложение** (React + Vite), собираемое в статику и раздаваемое
> nginx'ом. Своей БД и своего бэкенда у репозитория **нет**. Все данные приходят
> с внешнего API `aziral.com/api`, авторизация — сквозная (SSO) через межподдоменную куку.

## Ключевые факты

| Параметр | Значение |
|---|---|
| Тип | SPA, только фронтенд |
| Основной сайт | `https://aziral.com` (`VITE_MAIN_SITE_URL`) |
| API | `/api` → `aziral-backend:3001` |
| Dev-порт | `5174` |
| Прод | nginx в Docker, внешние сети `fenix-network` |
| Языки | RU, EN, KZ |
| Роли | `user`, `instructor`, `admin` |
| Объём кода | ~9 200 строк (без UI-примитивов), 48 UI-компонентов |

## Что важно помнить

> [!warning] Нет бэкенда в репозитории
> Ищешь миграции, модели, SQL, `.env`? Их здесь нет и не должно быть.
> Бэкенд и БД живут отдельно, на стороне `aziral.com`. Этот репозиторий —
> только слой представления.

> [!tip] Единственная сетевая дверь
> Весь HTTP идёт через `src/api/client.ts`. Новые запросы добавлять туда,
> а не через `fetch` по месту — иначе теряются `credentials: 'include'`
> и общая обработка ошибок. См. [[API клиент]].
