# Локализация i18n

Часть проекта [[learn-aziral]]. Файлы: `src/i18n/` — `index.ts`, `ru.ts`, `en.ts`, `kz.ts`.

Три словаря ровно по 314 строк каждый — держатся синхронно.
Стек: `i18next` 26 + `react-i18next` 17 + `i18next-browser-languagedetector`.

## Главная идея: СНГ → RU, остальной мир → EN

Обычный детектор просто читает язык браузера. Здесь (коммит `71f2e89`) написан
**свой детектор** `cisOrEnglish`, потому что для аудитории Казахстана и СНГ
логичнее русский, даже если система на английском.

Логика `detectCisOrEnglish()` (`src/i18n/index.ts`):
перебирает **весь** `navigator.languages` (а не только первый элемент) и для
каждого тега проверяет две вещи:

- **код языка** входит в `CIS_LANGUAGE_CODES` → `ru`;
- **код региона** входит в `CIS_COUNTRY_CODES` → `ru`.

Иначе — `en`.

**Языки:** ru, be, kk, ky, hy, az, tg, tk, uz, uk, ka, mo, ro
**Регионы:** RU, BY, KZ, KG, AM, AZ, MD, TJ, TM, UZ, UA, GE

> [!note] Тонкость с казахским
> В коде оставлен комментарий: Apple и Google используют код `kk`, а не `kz`.
> При этом сам **язык интерфейса** в проекте называется `kz`.
> То есть `kk` в браузере ведёт к `ru`, а не к казахской локали — это осознанно:
> `kz` включается только вручную через переключатель.

## Порядок определения

```ts
detection: {
  order: ["localStorage", "cisOrEnglish"],
  caches: ["localStorage"],
  lookupLocalStorage: "azr-lang",
}
```

Явный выбор пользователя всегда побеждает и хранится в `localStorage` под
ключом **`azr-lang`**. Детектор срабатывает только при первом заходе.
`fallbackLng: "en"`, `supportedLngs: ["ru", "en", "kz"]`.

Переключатель — `src/app/components/LanguageSwitcher.tsx`, встроен в `Navbar` (`b0a8330`).

> [!warning] Не всё переведено
> Часть строк захардкожена по-русски вне словарей — например, `LEVEL_CONFIG`
> и `COURSE_CATEGORIES` в `src/app/lib/constants.ts`, а также тексты ошибок
> в `src/utils/validation.ts`. При работе над локализацией начинать стоит оттуда.
