## Соглашения по коду

**Именованные экспорты для страниц.** Именно поэтому в роутере пишут
`.then(m => ({ default: m.CoursesPage }))` — `lazy()` требует default.

**Комментарии-разделители** в стиле
`// ── Название ────────────────` — приняты в `client.ts` и `validation.ts`.

**Язык комментариев смешанный**: в свежем коде и коммитах — русский,
в раннем — английский. Единого правила нет, пиши как вокруг.

**Формат коммитов** — Conventional Commits с русским описанием:
```
feat(profile): добавлен таб "Мои тесты" с прямой кнопкой создания
fix(mobile): полная адаптация TestBuilderPage под телефон
```
Используемые типы: `feat`, `fix`, `ci`, `ops`.

**Импорт по алиасу** `@/...` → `src/`.

## Ветки

## Технический долг — коротко

- прямые `fetch` в обход `src/api/client.ts` (`ProfilePage.tsx:177`,
  `TestBuilderPage.tsx:671`);
- слабая типизация API вне домена тестов (`object` вместо интерфейсов);
- страницы-гиганты: `InstructorPage` 1529 строк, `TestBuilderPage` 1446;
- русские строки вне i18n (`constants.ts`, `validation.ts`);
- `README.md` — до сих пор дефолтный шаблон Vite, о проекте в нём ничего нет;
- две несогласованные цветовые палитры (см. [[Архитектура]]).
