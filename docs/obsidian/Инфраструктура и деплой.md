# Инфраструктура и деплой

Часть проекта [[learn-aziral]].

## Сборка образа

`Dockerfile` — двухстадийный:
1. `node:20-alpine` → `npm ci` → `npm run build`;
2. `nginx:alpine` ← готовый `dist/` + свой `nginx.conf`.

Переменные подставляются **на этапе сборки** через `ARG`/`ENV`:

| Переменная | Значение по умолчанию | Смысл |
|---|---|---|
| `VITE_API_BASE_URL` | `""` (пусто) | пустая = относительный `/api` через nginx |
| `VITE_MAIN_SITE_URL` | `https://aziral.com` | куда уводить на вход |

> [!important] Vite-переменные вшиваются в бандл
> Поменять их без пересборки образа нельзя — это не рантайм-конфиг.

## nginx

Файл `nginx.conf`, ключевые блоки:

**Проксирование API**
```nginx
location /api/ {
    proxy_pass http://aziral-backend:3001/api/;
    proxy_cookie_domain ~(.+) .aziral.com;
}
```
Строка `proxy_cookie_domain` — критическая: она переписывает домен куки
на `.aziral.com`, без чего ломается SSO между поддоменами
(чинили в `d2b89a3`, до этого — `6229546` про имя контейнера).

**Кэширование**: хешированные ассеты — на год (`immutable`);
`index.html` — `no-cache, no-store, must-revalidate`, чтобы новые сборки
подхватывались сразу.

**SPA-fallback**: `try_files $uri $uri/ /index.html`.

**Заголовки безопасности**: `X-Frame-Options: SAMEORIGIN`,
`X-Content-Type-Options: nosniff`, `Referrer-Policy`, `X-XSS-Protection`.

**gzip** включён, уровень 6, от 1 КБ.

## docker-compose

Один сервис `learn-aziral`, `restart: always`, портов наружу не публикует —
подключён к **внешним** сетям `fenix_fenix-network` и `fenix-global-network`.
Наружу трафик выпускает NGINX Proxy Manager, стоящий перед контейнером.

## CI/CD

`.github/workflows/deploy.yml`, триггер — push в `main` или вручную.

1. **test**: Node 20 → `npm ci` → `npm test` → `npm run build`;
2. **deploy** (только если тесты прошли): SSH через `appleboy/ssh-action`,
   запускает скрипт на сервере:

```
/home/olzhas/bin/deploy-learn-aziral.sh
```

Скрипт (по комментарию в workflow) клонирует репозиторий, собирает образ,
пересоздаёт контейнер, **перезагружает NGINX Proxy Manager** — это лечит 502
после пересоздания — и проверяет, что отдаётся HTTP 200.

> [!note] Логика деплоя вынесена на сервер
> Коммит `1c11c37` намеренно упростил workflow до одной строки. Значит,
> сам скрипт деплоя в этом репозитории **не хранится** и правится на сервере.

Секреты: `SSH_HOST`, `SSH_USER`, `SSH_PRIVATE_KEY`.

## Локальная разработка

```bash
npm run dev     # порт 5174, /api → localhost:3001
npm run build   # tsc -b && vite build
npm test        # vitest run
npm run lint
```

Для полноценной работы нужен поднятый бэкенд на `localhost:3001`.
Есть `.claude/launch.json` с конфигурацией запуска dev-сервера.
