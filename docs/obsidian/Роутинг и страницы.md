# Роутинг и страницы

Часть проекта [[learn-aziral]]. Файл: `src/app/App.tsx`.

## Таблица маршрутов

| Путь | Экран | Доступ |
|---|---|---|
| `/` | `CoursesPage` | публично |
| `/courses/:id` | `CourseDetailPage` | публично |
| `/courses/:id/learn` | `CourseLearningPage` | вход |
| `/courses/:id/learn/:lessonId` | `CourseLearningPage` | вход |
| `/instructor` | `InstructorPage` | вход |
| `/instructor/courses/:id/build` | `CourseBuilderPage` | роль `instructor` |
| `/instructor/tests/:id/build` | `TestBuilderPage` | вход (роль **снята** намеренно) |
| `/profile` | `ProfilePage` | вход |
| `/study` | `StudyPage` | публично |
| `/study/:id` | `TestTakingPage` | публично |
| `/courses` | → `/` | редирект |
| `/login`, `/register` | → `aziral.com` | внешний редирект |
| `*` | → `/` | fallback |

| `CourseDetailPage.tsx` | 608 | витрина курса, запись, оценка |

| `StudyPage.tsx` | 510 | каталог самостоятельных тестов |

> [!note] Кабинет инструктора — три состояния
> Коммиты `a1f8c1a` и `834e49f`: вместо одного дашборда экран показывает
> разный интерфейс в зависимости от того, что есть у пользователя — ничего
> (Quick Start hero), только тесты, или курсы и тесты. Это ответ на то, что
> тесты открыли всем, а не только инструкторам.

## Общие элементы оболочки

- `ScrollToTop` (`App.tsx:27-31`) — скроллит вверх при смене `pathname`;
- `Navbar` — единая шапка, с мобильным гамбургер-меню (`bf67bf3`)
  и переключателем языка (`b0a8330`);
- `PageLoader` — спиннер на тёмном фоне, он же fallback для `Suspense`;
- `Toaster` из sonner — уведомления снизу справа, тёмная тема;
- `ErrorBoundary` — есть в компонентах, ловит падения рендера.

## Хуки

`usePageTitle` (`src/app/hooks/usePageTitle.ts`) — единственный кастомный хук,
проставляет `document.title`.
