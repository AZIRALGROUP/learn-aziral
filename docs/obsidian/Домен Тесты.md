# Домен Тесты

Часть проекта [[learn-aziral]]. Самая проработанная и самая живая подсистема.

## Что это

«Standalone tests» — тесты, **не привязанные к курсу**. Появились в коммите
`1e2f194` и с тех пор переписывались чаще всего остального. Отличать от
**квизов**, которые живут внутри уроков (`instructorApi.getQuizzes`).

## Модель данных

```ts
interface TestSummary {
  id, title, description, category, status,
  instructor_name, question_count, created_at, updated_at
}

interface TestQuestion {
  id, test_id, question,
  type: 'single' | 'multi' | 'tf' | 'order',
  options: string[],
  items: { text: string; order: number }[],
  correct: number[],
  count: number,
  order_num: number
}
```
Источник: `src/api/client.ts:100-111`.

## Четыре типа вопросов

| Тип | Смысл | Особенность |
|---|---|---|
| `single` | один правильный ответ | выбор мгновенно проверяется |
| `multi` | несколько правильных | поле `count` — сколько ждать; чинили в `be93ede` |
| `tf` | правда / ложь | частный случай `single` |
| `order` | расставить в хронологическом порядке | использует `items`, не `options` |

В `TestTakingPage.tsx:206` `single` и `tf` обрабатываются одной веткой,
а `order` везде идёт особым путём — в том числе он **исключён из
горячих клавиш** `1`–`9` (`TestTakingPage.tsx:249`) и из мгновенной
проверки (`:236`).

## Прохождение теста

Экран показывает разбивку по типам вопросов ещё до старта
(`TestTakingPage.tsx:35-84`), есть опция **перемешивания** (`shuffle`)
и навигация с клавиатуры цифрами.

## Конструктор — четыре способа завести вопросы

`TestBuilderPage.tsx` (1446 строк) — здесь сосредоточена основная сложность:

1. **Вручную** — обычная форма.
2. **JSON-импорт** (`:608-616`) — терпимый парсер: принимает массив,
   объект `{ questions: [...] }` или одиночный вопрос.
3. **Quick Input** (`parseQuickText`, `:691`) — разбор текста, набранного
   в свободной форме; счётчик найденных вопросов показывается вживую (`:1381`).
4. **Таблица** (`parseSpreadsheet`, `:747`) — импорт из xlsx/csv через
   библиотеку `xlsx`.

Всё сходится в один эндпоинт `POST /instructor/tests/:id/import`.

**ИИ-генерация вопросов** (`b35a012`): `POST /instructor/ai/generate-questions`,
вызывается напрямую через `fetch` в обход клиента (`:671`).

Плюс **автосохранение** (`e66130a`) и публикация через
`PATCH /instructor/tests/:id/publish` (переключатель `status`).

## Кто имеет доступ

Изначально тесты были только для инструкторов. Коммит `100124b` снял проверку
роли с маршрута конструктора — теперь **любой залогиненный** может создать тест,
а владение проверяет бэкенд. Из-за этого в профиле появился таб «Мои тесты»
(`ee1ab6c`), а кабинет инструктора перестроили (`834e49f`).
