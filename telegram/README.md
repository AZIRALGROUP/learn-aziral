# Aziral Learn в Telegram

Бот: [@Learn_Aziral_bot](https://t.me/Learn_Aziral_bot). Постоянная Mini App: [learn-bot.aziral.com/telegram](https://learn-bot.aziral.com/telegram). С 21 октября 2026 сервер работает на Netcup; Mac и временный туннель не нужны. Эксплуатация и откат: [netcup.md](netcup.md).

## Что реализовано

- Вход по серверно проверенному `Telegram.WebApp.initData`, без паролей и перехода на SSO сайта.
- Свои тесты: создание, редактирование, личные черновики, публикация в общей библиотеке.
- Вопросы с одним и несколькими правильными ответами, правда/ложь и порядок, тренировка и оценка. Локальный редактор создаёт вопросы с одним ответом; остальные форматы сохраняются при загрузке тестов сайта.
- Генерация 1–10 вопросов по теме или конспекту через Gemini; обязательная проверка человеком перед сохранением.
- Текстовые курсы с уроками и индивидуальным прогрессом.
- Дуэль на двоих по приглашению: 3 секунды до старта, 15 секунд на вопрос, до 10 случайных вопросов из больших тестов, серверное время, один ответ на раунд.
- За верный ответ — 1000 очков; за скорость — до 150. Ответы и результаты дуэли скрыты до конца.
- Команды `/start`, `/learn`, `/tests`, `/courses`, `/duel ID`, `/help` в личных чатах и группах.
- Отдельная SQLite-база. Сервер сохраняет снимок вопросов для тренировки и дуэли: редактирование теста не меняет текущую игру.

Каталог сайта подключён через защищённый внутренний API: **17 курсов и 50 опубликованных тестов (3017 вопросов)** на момент размещения. 16 черновиков сайта не публикуются в Telegram. Копии каталога не создаются: изменения сайта доступны при следующей загрузке. Для уроков сайта доступны текст, ссылки на видео, условия заданий и тесты к уроку. Полный интерфейс заданий и редактирование исходных материалов остаются на сайте.

Учётная запись определяется по подтверждённому `users.telegram_id`. Пользователь привязывает Telegram в профиле `aziral.com`. Оплаченные курсы открываются только при существующем подтверждённом доступе, автору или администратору; привязка сама по себе не подтверждает оплату. Блокировка аккаунта сайта запрещает доступ к его материалам. 11 бесплатных курсов можно изучать без привязки; 6 платных сохраняют ограничения сайта.

Отметка урока для привязанного аккаунта сохраняется в прогрессе сайта и начисляет XP один раз. До привязки прогресс бесплатных курсов хранится в боте по постоянным ID уроков. После привязки показывается прогресс сайта; прежние локальные отметки не переносятся автоматически. Результаты отдельных тренировок и дуэлей остаются в базе бота. Созданные в боте материалы пока не экспортируются в редактор сайта. Массовых турниров и общего рейтинга пока нет.

## Бесплатный ИИ

Проверено 21 октября 2026: `gemini-3.5-flash-lite` доступен на Free tier. Реальный запрос с новым ключом успешно создал три вопроса. `gemini-2.5-flash-lite` отклонён Google как недоступный новым пользователям, поэтому не используется.

- У Free tier есть меняющиеся квоты; гарантии бесплатной работы навсегда нет.
- Квота привязана к Google-проекту, а не к отдельному ключу. Создание ещё одного ключа не увеличивает её.
- Проект Google должен оставаться на Free tier **без подключённого биллинга**. Приложение не подключает биллинг и не переключается на другую модель автоматически. Сам ключ не определяет тариф: если владелец позже включит оплату в Google, серверный флаг не сможет отменить её.
- Генератор выключен без `GEMINI_FREE_TIER_CONFIRMED=true`.
- Локальная защита квоты: до 5 генераций в сутки на пользователя и 30 на сервер; повтор той же темы/конспекта от того же пользователя в течение суток берётся из кеша. Лимиты Google могут быть ниже. Сутки локального лимита — UTC.
- Одна генерация за раз, без автоматических повторов. Ошибка 429 приостанавливает новые запросы к Google на 30 минут в текущем процессе.
- Сохранённые тесты, курсы и дуэли не используют ИИ и работают при исчерпанной квоте.
- Free tier допускает использование Google отправленного материала для улучшения сервисов. Интерфейс предупреждает об этом и требует согласия перед отправкой. Не вставляйте личные или конфиденциальные данные.

Источники: [тарифы](https://ai.google.dev/gemini-api/docs/pricing), [квоты](https://ai.google.dev/gemini-api/docs/rate-limits), [обработка данных](https://ai.google.dev/gemini-api/terms).

## Локальный запуск

Нужен **Node 24+** (встроенный `node:sqlite`). Дополнительных серверных npm-зависимостей нет.

Секреты находятся в `.env.telegram.local`; файл игнорируется Git и Docker. Пример без значений — `telegram/env.example`. Реальные секреты нельзя помещать в `VITE_*`: такие переменные попадают в браузерную сборку.

```sh
npm ci
npm run build
npm run telegram:dev
```

Сервер отдаёт сборку и API на `http://localhost:3002/telegram`. Без Telegram-подписи в рабочем режиме пользователь не авторизуется.

Для отдельного локального просмотра в обычном браузере:

```sh
TELEGRAM_DEV_MODE=true TELEGRAM_PORT=3003 TELEGRAM_DATABASE=telegram/data/preview.sqlite npm run telegram:dev
```

Тогда откройте `http://127.0.0.1:3003/telegram`. Просмотр использует отдельного пользователя `dev-1` и отдельную базу. Сервер в этом режиме привязан к loopback; `NODE_ENV=production` запрещает обход авторизации. **Нельзя направлять публичный туннель или reverse proxy на сервер с `TELEGRAM_DEV_MODE=true`**: прокси тоже подключается с loopback.

Для разработки с Vite: запустите сервер на 3002 и `npm run dev`; `/api/telegram` проксируется на 3002. Остальной `/api` остаётся на прежнем backend (3001).

## Запуск бота

В `.env.telegram.local` задаются `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, публичный HTTPS `MINI_APP_URL` с путём `/telegram`, `GEMINI_API_KEY` и подтверждение Free tier. Файл должен иметь права `600`.

```sh
npm run telegram:setup
npm run telegram:seed
npm run telegram:poll
```

Setup задаёт название, короткое описание, приветственное описание профиля, меню «Учиться» и команды. После сборки `npm run telegram:setup -- --profile-photo` загружает фирменный аватар из `dist/telegram/avatar.jpg`; Сгенерированный оригинал — `public/telegram/learn-aziral-logo.png`, версия для Mini App — `public/telegram/learn-aziral-logo.webp`. Логотип создан встроенным imagegen; промпт сохранён в `telegram/logo-prompt.txt`. `avatar.svg` — прежний знак Aziral, текущий интерфейс его не использует. Без этого флага фотография повторно не загружается. Polling проверяет отсутствие webhook и не удаляет чужую настройку. Поддерживайте только один процесс polling на токен. Не запускайте polling и webhook одновременно.

В приветствии — короткий текст и одна кнопка «Открыть Learn». В списке команд — `/start`, `/duel`, `/help`; прежние `/tests`, `/courses`, `/newtest`, `/progress` продолжают открывать нужный раздел одной кнопкой. Добавление в группу перенесено в личную помощь `/help` и не требует прав администратора. В личных сообщениях обычный текст вызывает помощь; в группе бот отвечает только на свои команды. Старые сообщения не меняются: для нового меню отправьте `/start`.

Тренировки автоматически сохраняются на сервере после выбора ответа и перехода между вопросами. Индикатор показывает сохранение или ошибку; «Сохранить и выйти» ждёт завершения записи. После закрытия можно продолжить через карточку на главной или раздел «Прогресс», в том числе на другом устройстве. При одновременном редактировании в двух окнах устаревшая версия получает 409 вместо перезаписи ответов. Перед завершением теста приложение предупреждает о пропусках.

«Прогресс» показывает последние 20 результатов и до 5 незавершённых тренировок; результаты можно открыть для разбора и повторить только ошибки либо весь снимок теста. Данные принадлежат проверенному Telegram ID. Доступ к материалу сайта повторно проверяется перед продолжением, разбором и повтором. Существующая база обновляется созданием таблицы `attempt_details` без удаления прежних данных; у старых результатов без метаданных дата отсутствует. Результаты тренировок и дуэлей хранятся у бота, синхронизация с сайтом относится к урокам.

Необязательный `telegram:seed` добавляет один демонстрационный тест по математике и вводный курс. Повторный запуск не меняет существующие материалы. Это отдельные примеры, а не перенесённые данные старого сайта.

В группе бот отвечает на команды, например `/learn@Learn_Aziral_bot`; читать все сообщения группы ему не требуется. Отключать privacy mode или выдавать права администратора не нужно. Ссылка приглашения имеет вид `https://t.me/Learn_Aziral_bot?start=duel_ID`: бот в личном чате выдаёт кнопку нужной дуэли. Этот путь работает без отдельной настройки Main Mini App у BotFather.

Mini App использует компактные карточки и заголовки. В редакторах раскрывается один вопрос или урок; дополнительные поля свёрнуты, сохранение закреплено снизу. Проверка формы раскрывает первое ошибочное поле и переводит на него фокус; ответы в закрытых блоках сохраняются.

## Постоянное размещение

```sh
docker compose -f compose.telegram.yml up -d --build
```

Это отдельный сервис, который слушает 127.0.0.1:3002 на хосте. Подключите имеющийся HTTPS reverse proxy на выделенном поддомене (например `learn-bot.aziral.com`) к этому порту. Он должен пропускать `/telegram`, `/assets/*` и `/api/telegram/*` в этот сервис. Не используйте `X-Frame-Options: SAMEORIGIN` для Mini App: Telegram Web открывает её в iframe. Сервер задаёт ограниченный `frame-ancestors` для Telegram. Cloudflare Pages сам не исполняет этот Node/SQLite-сервер; существующий catch-all API-прокси сайта не ведёт на новый Telegram API.

Далее задайте постоянный `MINI_APP_URL`, случайный `TELEGRAM_WEBHOOK_SECRET` (не менее 32 символов) и выполните:

```sh
npm run telegram:setup -- --webhook
```

Setup не перезаписывает webhook с другим URL. Проверка токена webhook происходит до разбора запроса. После настройки polling не нужен. База хранится в Docker volume `telegram-learn-data`; делайте резервные копии SQLite штатным backup-механизмом с учётом WAL. Не удаляйте volume при обновлении.

Quick Tunnel Cloudflare подходит только для просмотра: его URL меняется и перестаёт работать после остановки процесса или Mac. Это не постоянное размещение.

## Проверки

```sh
npm run telegram:test
npm test
npx eslint src/telegram src/EntryApp.tsx src/main.tsx
npm run build
```

Backend-тесты не вызывают реальные Telegram/Gemini API. Они проверяют поддельную/просроченную подпись, приватность черновиков, права автора, скрытие ответов, неизменяемый снимок тренировки, прогресс, двух участников дуэли, сроки и повторные ответы, серверный подсчёт, дедупликацию команд и ограничения Gemini. `npm test` запускает frontend-тесты, включая Mini App. GitHub workflow на Node 24 выполняет frontend-тесты, `telegram:test` и сборку при push в `main`. Его отдельный этап `deploy` вызывает прежний SSH-скрипт сайта; он не обновляет Telegram-контейнер Netcup. Обновление бота выполняется по инструкции в `telegram/netcup.md`.

SQLite-сервер рассчитан на один экземпляр API с локальным диском, не на горизонтальное масштабирование. AI-квоты в SQLite общие для процесса бота и API; ограничение частоты HTTP и пауза после 429 живут в памяти процесса. Таблицы попыток, игр и обновлений пока не имеют автоматической политики удаления — её следует определить перед массовым запуском.
